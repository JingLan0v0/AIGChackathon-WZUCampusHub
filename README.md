## 一、要解决什么问题

学生每天要查的东西，散在五六个地方：

| 想做的事 | 现在的代价 |
|---|---|
| 想知道今天穿什么 | 再开一个天气 App / 网页 |
| 想记住作业 DDL | 打开备忘录，自己再敲一遍 |
| 想看课表 | **先过统一身份认证**，再在一堆菜单里找入口 |
| 想确认有没有调课 | 翻教务系统，翻不到就当没发生 |
| 想找失物 | 微信群爬楼，刷过去就没了 |

问题不在「功能不够」，在**入口太散、会漏、记不住**。
所以我们做的不是又一个小工具，而是**把这些收进一个入口，并且让它听得懂人话**。

## 二、功能一览

**七个模块**：

| 模块 | 做什么 |
|---|---|
| 🏠 首页 | 左侧天气、今日规划与校园信息；右侧校园 AI 助手（约 3:1） |
| 🧭 今日规划 | 按课表空档、DDL、重要度自动排出「现在最该做什么」 |
| 📅 智能课表 | 按用户课表截图显示**13 节作息**；支持课表 PDF 识别导入 |
| 📝 作业 DDL | 倒计时、逾期提醒、一键完成 |
| 🔍 失物招领 | 丢了 / 捡到分开找 |
| 💬 校园问答 | 选课、食堂、报修都有人答 |
| 👤 我的 | 学籍、数据导入导出、多账号一键切换 |

**AI 实际在做的四件事**（不是贴标签，是替代学生「自己想、自己敲、自己翻」）：

1. **自然语言 → 结构化**：`明晚 7 点 图书馆自习 2 小时` → 日期 / 时刻 / 时长 / 地点 / 类型 / 重要度
2. **意图识别**：判断这是「作业 DDL / 课外计划 / 课表补充 / 请假条」，四类四种处理路径
3. **文本生成**：一句话生成**正式请假条正文**（抬头、学号、时间、补课承诺、落款），一键复制发给老师
4. **课程调整**：在首页 AI 输入文字或上传调课截图，核对课程、周次、节次和教室后更新课表
5. 另外还有：课表 PDF 识别（`8:20` → 第 1 节）、天气 → 出行建议、今日规划自动排程

## 四、技术选型与理由

| 选择 | 为什么 |
|---|---|
| **静态页面 + 本地 Node 服务**（无框架、无构建、无运行时 npm 依赖） | 双击就能跑；答辩现场不赌网络；评委拉下来 5 秒能开 |
| **事项数据放 localStorage** | 确认后的内容保存在当前浏览器；AI 仅接收本次请求、相关模块的简要记录和最近 4 条短消息，不发送账号密码或完整备份 |
| **每个学号一份独立数据槽** | 多账号互不干扰；「我的」页可一键切换 |
| **首页自然语言输入由本地服务调用 DeepSeek Flash** | 支持查询、增删改完成、调课、失物、问答、资料与数据管理；所有修改先核对确认。普通查询和导航在本地执行，复杂请求通过本地服务识别 |
| **pdf.js 本地内置（`assets/vendor/pdfjs/`）** | 课表 PDF 识别也能离线完成 |

除了用户发送复杂操作请求时的 DeepSeek 识别请求，外部请求还包括**天气**，而且是三源并行、谁先回来用谁：国内源（UAPIS）优先，配 Open-Meteo / wttr.in 兜底，再加 30 分钟缓存 —— 全挂了也会显示上次的数据，而不是一片空白。

## 五、课表 PDF 导入

1. 学生自己登录教务系统，导出课表 PDF。
2. 在首页 AI 对话区点击「📄 PDF」，或在课表页、个人中心选择 PDF；导入弹窗也支持拖拽上传。
3. 浏览器本地提取 PDF 文字并识别课程，核对预览后确认替换课表。

课表导入仅提供 PDF 入口；扫描件或截图转出的 PDF 无法提取文字时会明确提示。此流程不读取登录密码，不上传 PDF。

## 六、测试与质量

项目提供数据逻辑、页面交互、PDF 识别、AI 接口和资源引用检查：

```bash
npm install                     # 只装测试用的 jsdom / pdfjs-dist（应用本身零依赖）
npm run test:syntax             # JavaScript 语法检查
npm test                        # 逻辑、页面交互、PDF 识别与引用一致性
npm run test:ai                 # AI 请求、动作校验与服务安全性
```

| 测试文件 | 覆盖 |
|---|---|
| `tests/logic.test.js` | 数据层、作息表、规划引擎、天气兜底、调课解析、多账号隔离 |
| `tests/ui.test.js` | 用 jsdom 运行页面并验证交互和数据写入 |
| `tests/pdf.test.js` | 使用样本 PDF 验证课表识别与节次映射 |
| `tests/consistency.test.js` | CSS / HTML / JS 三方引用一致，防止「改了旧文件、页面还是旧的」 |
| `tests/deepseek.test.js`、`tests/assistant.test.js` | AI 请求、动作白名单、时间锚定、密钥隔离和同源限制 |

> 测试里的「现在」是**钉死**的（固定在某教学周周二 09:30）：否则示例课表周二才有课、周末跑就会红一片。踩过的坑都写成了断言。

## 八、开发过程

例如这些真实需求：

- 「将课表的时间改为我给你的图」→ 把作息表抽成单一数据源，并把课表、今日规划、调课通知、PDF 识别、抓取脚本一起改掉，重跑全量测试

## 九、已知限制（说实话）

- **课表 / 成绩数据不能自动同步**：统一身份认证是网易 SSO + 人机验证，静态页直连拿不到会话；目前靠「同源脚本 + 一键导入」。正式版需要一个小后端持会话。
- **天气依赖外部接口**：已做三源兜底与缓存，但极端网络下仍可能取不到（界面会明确写「天气未取到」，不会假装有数据）。
- **数据存在本机**：换设备 / 清浏览器缓存会丢；「我的」页提供导出 / 导入 JSON。
- **课程调整不自动读取教务通知**：课表里的通知卡片和演示通知已移除；需要本人在首页 AI 输入调整，或上传截图识别并确认。

## 自然语言识别与本机密钥

运行 `npm run serve` 后，首页“记下来”使用 DeepSeek Flash 非思考模式识别中文日期、时刻、课程、作业、地点与请假信息。识别结果仍需确认才会写入浏览器数据。调用失败会明确提示重试。

文字请求只发送本次输入、当前本地时间与相关课程的简要信息；选择截图时会额外发送压缩后的图片给 DeepSeek Flash 识别。不发送学号、登录密码或整个本地数据库。课表之外无法确定的地点与教师保持为空。

Windows 首次配置：运行 `campus-hub/tools/set-deepseek-key.ps1`，在隐藏输入中填写自己的 DeepSeek 密钥。密钥由 Windows DPAPI 当前用户加密，存于 `%LOCALAPPDATA%/CampusHub/deepseek.dpapi`，不在 Git 仓库内。同一 Windows 用户下运行的本地服务读取它；换电脑或换用户需要重新配置。

前端没有密钥，服务只监听 `127.0.0.1`，仅接收同源的 JSON 识别请求，限制请求大小、并发与频率。服务器不提供 tools 或隐藏文件的下载，也不回传上游的原始错误。`.env`、`.dpapi` 和 `.key` 文件加入 Git 忽略规则。

校验：`npm run test:ai`，覆盖结构化结果、敏感上下文过滤、同源限制、私有文件访问与错误脱敏。

## 首页校园 AI 助手

首页按约 3:1 分为信息区和对话区，助手保持在右侧，可独立滚动。可以说“把数据结构作业改到明晚九点截止”“数据结构第 3 周周二第 6–7 节调到周四第 3–4 节，改在计算机楼 402”“发布一条图书馆捡到水杯的信息”，也可以查询、筛选或打开各模块。课程调整支持调课、停课、补课和换教室；也可以点击对话框的“📎 截图”上传照片或直接粘贴截图。点击「📄 PDF」即可上传并在本机识别课表，核对预览后确认替换。备份导入会打开文件选择入口，由用户选择本机文件。

模型只返回受限操作列表，不能执行代码。涉及写入、删除、清空或账号操作都会先展示核对卡，允许调整或取消；确认时再校验记录是否变化，批量失败回滚，失物和提问限制为本人内容。调课截图只在本次识别时发给 DeepSeek Flash，不保存在聊天记录或本机数据库；未确认的调整不会写入课表。

节省 token：常用查询、导航、天气刷新和导入入口直接本地处理；复杂请求使用 DeepSeek Flash、关闭思考、只附相关模块的有限摘要与最近 4 条短消息，每次最多 6 项操作、输出上限 1400 tokens。密钥仍由本地服务读取仓库外的 DPAPI 加密文件，前端无法读取，提交 Gitee 不包含密钥。

任务分区：全部学业事项（作业、自习、背单词、复习、错题与专业训练）在待办清单展示，非学业事项（运动、生活、社交与娱乐）在课外计划展示。旧计划刷新后自动归类，保留原日期、时段、重复、重要度、备注与完成记录；今日时间轴仍合并两类事项。AI 查询待办会同时读取作业与学业任务，按真实记录修改或完成，普通学业任务不必伪装成有截止时间的作业。
